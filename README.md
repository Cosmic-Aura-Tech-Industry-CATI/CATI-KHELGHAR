# 🎮 CATI KHELGHAR

> **Pure local multiplayer & AI board games for family and friends. 100% offline, zero servers, zero logins.**

---

## 🌟 Overview
**CATI KHELGHAR** is a modern progressive web application (PWA) built with **Next.js 14**, **React 18**, and **Tailwind CSS**. It brings classic tabletop games directly to your device screen for pass-and-play local multiplayer or single-player matches against intelligent AI Bots.

---

## 🎲 Available Games

1. ❌⭕ **Tic Tac Toe** - Classic handcrafted wooden aesthetic with 3D sculpted Charcoal 'X' & Terracotta 'O', featuring an unbeatable Minimax heuristic AI bot.
2. 🔴🟡 **Four in a Row** - 7×6 gravity drop board with physics disc drop animations and 4-in-a-row detection.
3. 🐍🪜 **Snake & Ladders** - 100-cell zigzag board with SVG vector snakes & ladders, step-by-step token hopping animations, and tactile 3D dice.
4. 🎲 **Ludo** - 15×15 Indian Ludo with star-safe zones, yard deployment, token captures with fanfare, and smart bot decision making.
5. ✏️📦 **Dots & Boxes** - Dotted parchment board with 3×3 and 4×4 tactical modes, box claiming, and chaining bonus turns.
6. 🎯 **Carrom** - Authentic Indian Carrom tabletop board with 2D physics collisions, baseline striker slider, aim angles, power meter, Queen (25 pts), White (10 pts), and Black (5 pts) scoring.

---

## ✨ Features

- 🤖 **AI Bot vs. Human**: Play solo against smart bots or pass-and-play with 2 to 4 people.
- 📶 **100% Offline Ready**: Fully functional offline via Service Worker caching.
- 🔒 **Zero Data Collection**: No accounts, no cookies, no tracking. All game scores saved locally in `localStorage`.
- 🔊 **Procedural Web Audio API**: Crisp sound effects and victory fanfares generated dynamically without external audio assets.
- 📱 **Responsive & Mobile-First**: Optimized for phones, tablets, and desktop displays.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Cosmic-Aura-Tech-Industry-CATI/CATI-KHELGHAR.git

# Navigate to project directory
cd CATI-KHELGHAR

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
